# Proposal

## Why

Студенту нужно быстро видеть, сколько учебной работы на неделю запланировано и какая доля уже выполнена. Сейчас инструмента нет: нужен автономный мини-трекер учебных задач, который открывается локально без сервера, CDN, внешних библиотек и API-ключей, а прогресс считает по часам, а не по числу задач (см. brief.md).

## What Changes

- Новый автономный веб-трекер учебных задач на неделю (файлы `index.html`, `styles.css`, `app.mjs`, `domain.mjs`).
- Модель задачи: `id`, `title`, `hours`, `done`; стартовый пример — «Чтение» 2 ч (готово), «Практика» 4 ч (активно), «Повторение» 2 ч (активно).
- Добавление, удаление и переключение статуса `done`, которые реально меняют данные и интерфейс (R1).
- Валидация формы: название после trim непустое; часы — число 0,5–24 с шагом 0,5; пустое значение не равно нулю; ошибка показывается рядом с полем, введённые значения сохраняются (R2).
- Метрики: всего часов, выполнено часов, прогресс = округление(100 × часы done / все часы); при пустом списке — 0 ч и 0%, без NaN/Infinity (R3, R5).
- Фильтр «все / активные / выполненные», влияющий только на видимый список; итоги и прогресс считаются по всем задачам (R4).
- Адаптивная вёрстка: читаемость на ширине 390 px без горизонтального скролла, подписанные поля и кнопки (R6).
- Автоматические приёмочные тесты `tests/acceptance.test.mjs` на `node:test` по проверкам T1–T5 (расчёт 25%/75%, независимость метрик от фильтра, валидация, пустое состояние).
- Необязательно: сохранение задач в localStorage с понятным сообщением и работой в памяти, если хранилище недоступно.

### Не входит в изменение

- Серверная часть, backend, API и база данных.
- Учётные записи, авторизация, многопользовательский режим.
- Синхронизация между устройствами или браузерами, облачное хранение.
- Внешние библиотеки, фреймворки, CDN, сборщики, API-ключи.
- Сроки, приоритеты, категории, напоминания и прочие поля сверх `id/title/hours/done`.
- Автоматизированное браузерное (E2E) тестирование: форма, кнопки, тексты ошибок и узкий экран проверяются вручную.

## Capabilities

### New Capabilities

- `tracker`: ведение списка учебных задач на неделю — CRUD статусов, валидация ввода, расчёт часов и прогресса, фильтрация видимого списка, пустое состояние и требования к доступности/адаптивности интерфейса.

### Modified Capabilities

- Нет (в проекте ещё нет спецификаций).

## Impact

- Новые файлы в корне проекта: `index.html`, `styles.css`, `app.mjs`, `domain.mjs`, `tests/acceptance.test.mjs`.
- Зависимости: только встроенные возможности браузера и Node.js 22 (`node:test`, `node:assert`); внешних пакетов нет.
- Запуск тестов: `node --test tests/acceptance.test.mjs`.
- Ограничение: при открытии `index.html` через `file://` поддержка ES-модулей и localStorage зависит от браузера — это описывается в design.md и учитывается при ручной проверке.
