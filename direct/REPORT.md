## Решения и допущения
- Прогресс = `Math.round(100 × doneHours / totalHours)`, при `totalHours = 0` → 0.
- Часы: принимаются «1,5» и «1.5»; пустая строка/пробелы — ошибка «Укажите часы.» (не 0); диапазон 0,5–24; кратность 0,5.
- Метрики всегда считаются по всему массиву задач, фильтр влияет только на список.
- Новая задача создаётся с `done=false`.

# Исправление дефекта 01

Основа — `bugfix-01.md`. Правила `brief.md` и `redesign-brief.md`, значения T1–T5 и прежние тесты не менялись.

## Причина
1. Страница подключала `app.mjs` как ES-модуль (`type="module"`). При file:// и в iframe с `sandbox` без `allow-same-origin` у документа непрозрачный origin (`null`), поэтому Chromium блокирует загрузку модуля по CORS и приложение не запускается совсем.
2. Задача добавлялась только через событие `submit` формы: кнопка была `type="submit"`, Enter срабатывал через неявную отправку. В iframe `sandbox` без `allow-forms` браузер блокирует отправку формы ещё до события `submit`, поэтому обработчик не вызывался.
3. Сопутствующий риск: при непрозрачном origin исключение `SecurityError` бросает уже само обращение к `window.localStorage`. Раньше оно было внутри try, но различение ошибок шло по типу (`SyntaxError`); теперь доступ к хранилищу вынесен в отдельную защищённую функцию.

## Что изменено
- `app.mjs`:
  - вся логика добавления собрана в одну функцию `handleAdd()` (валидация `addTask` из domain.mjs);
  - кнопка «Добавить» вызывает её по `click`;
  - поля «Название» и «Часы» вызывают её по `keydown`: только Enter, без Shift и не во время IME-композиции (`isComposing` / `keyCode 229`), с `preventDefault`;
  - `submit` формы оставлен на случай обычного открытия: он отменяется и вызывает ту же функцию;
  - поля очищаются вручную, без `form.reset()`;
  - новая функция `getStorage()` берёт `window.localStorage` в try. При `SecurityError` или отсутствии хранилища приложение показывает сообщение и работает в памяти. Повреждённый JSON молча заменяется значениями по умолчанию.
- `index.html`: кнопка теперь `type="button"`, подключение — `<script src="tracker.js" defer></script>`, `type="module"` больше нет.
- `build.mjs` (новый, чистый Node без зависимостей):
  - склеивает `domain.mjs` и `app.mjs`, убирает `import` и префиксы `export`, оборачивает результат в IIFE с `'use strict'`;
  - если встречается неподдерживаемый синтаксис модуля, падает с ошибкой;
  - экспортирует `buildTracker()` для теста.
- `tracker.js`: сгенерирован командой `node build.mjs`, вручную не редактировался.
- `tests/acceptance.test.mjs`: прежние 11 тестов не изменены, добавлены 3 теста B01:
  - `tracker.js` побайтно совпадает с `buildTracker()`;
  - `tracker.js` — классический скрипт: в нём нет import/export, код обёрнут в IIFE и компилируется через `new Function`;
  - `index.html` подключает `tracker.js` без `type=module`, кнопка имеет `type="button"`, в `app.mjs` есть обработчики click и keydown/Enter.
